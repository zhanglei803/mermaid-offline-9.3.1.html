单文件离线 Mermaid 图表工具，内网环境可用，无需额外安装软件。

## 功能

- Mermaid 9.3.1 本地渲染，不依赖外网
- 导入本地 `.md` 文件，自动提取全部 `mermaid` 代码块
- 多图表下拉切换，支持源码编辑，实时预览
- 一键清空全部内容
- 导出 SVG（矢量无损）、高清 PNG，自动处理长图、裁除多余空白
- 所有运算在浏览器本地完成，不上传任何数据

## 环境要求

- Chromium 内核浏览器（Chrome / Edge / 国产 Chromium 浏览器）
- 离线内网环境，仅需单个 HTML 文件，无其他依赖

## 使用方法

1. 双击 `mermaid-offline-9.3.1.html`，浏览器打开
2. 导入 MD 文件，自动解析所有 Mermaid 图表；也可手动粘贴 Mermaid 源码
3. 下拉框切换图表，修改源码实时预览
4. 导出 SVG / PNG
5. 一键清空重置页面

## 注意事项

1. 仅识别标准 ```mermaid 代码块
2. 超大 MD 文件、大量复杂图表渲染速度会下降
3. 推荐使用 Chromium 内核浏览器
